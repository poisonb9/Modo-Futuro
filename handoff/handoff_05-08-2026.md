## 3 bugs reais de infra achados e corrigidos (todos no `main`)

1. **Secret do GitHub desatualizado**: `GOOGLE_OAUTH_TOKEN_JSON` (usado
   pelo Actions) tinha o token OAuth velho/expirado da conta `principal`.
   O conserto de 03/08 (`modofuturo-principal-drive-token-fixed.md`) só
   tinha atualizado o `token_drive.json` **local** — o secret do GitHub é
   um lugar independente que também precisa ser atualizado, e ninguém
   tinha feito isso. Corrigido via API (criptografando o token local com
   a chave pública do repo, PyNaCl `SealedBox`, PUT em
   `/actions/secrets/GOOGLE_OAUTH_TOKEN_JSON`).
2. **Disco cheio no meio do lote** (`main.py`): os arquivos intermediários
   de cada clipe (`bruto_*.mp4`, `dub_*/`, `.flac`, `.ass`) só eram
   limpos no FIM do lote inteiro, não por clipe. Corrigido: agora cada
   clipe limpa os próprios temporários assim que termina (commit
   `9c4cb64`).
3. **Disco cheio antes até de instalar o modelo** (`cortar_de_bruto.yml`):
   o runner padrão do Actions só tem ~14GB livres de fábrica, e SDKs
   pré-instalados que o job nunca usa (Android, .NET, GHC) já ocupam boa
   parte disso. Com `--dublar` (torch + chatterbox-tts + pesos do modelo,
   ~2GB) isso não cabia. Corrigido: novo step "Liberar espaço em disco"
   remove esses SDKs não usados antes de instalar (commit `1c859b7`),
   libera 20-30GB.

**Nenhum desses 3 bugs precisa de atenção — já corrigidos e no `main`.**
