# Modo Futuro — `@modofuturo`

Chips, fabrica, maquina e tecnologia, contados pelo lado FISICO e EXTREMO.

## Receita de disparo

| parametro | valor |
|---|---|
| `canal` | `modofuturo` |
| `idioma` | o da fonte (`en` na maioria) |
| `dublar` | `true` |
| `fala_literal` | **`false`** |
| `voice_over` | **`false`** |
| `estilo_legenda` | `2` |

Narracao de CONTEXTO, nao fala literal: aqui o valor esta' no fato, nao na
frase exata que a pessoa disse.
