## 1. 🔴 OS DESCONTOS FALSOS — a causa raiz

O Bryan mandou print: *"como que esse anúncio sai de 20,82 para 6,32 e o
gráfico está reto?"*

### O que era

O AliExpress devolve, **sob um mesmo `id` de produto**, preços de **ofertas e
variantes diferentes**. `target_sale_price` e `target_original_price` sobem e
descem juntos, com `discount%` idêntico. Nós líamos a leitura cara de um dia
como "o maior preço que já vimos" e anunciávamos uma queda que nunca houve.

**Medido:** 32 dos 45 picos do catálogo caíam em 20–21/09.

### O que eu fiz — `engine/serie_limpa.py`

Três regras, nesta ordem de precedência:

```
1. EXCECAO_MANUAL  — por ID, decidida pelo Bryan, nunca genérica
2. oferta dupla CONFIRMADA  — sai sozinha
3. isolamento temporal  — o pico de um dia só, cercado de dias normais
```

**Exceções manuais em vigor (2):**
```python
EXCECAO_MANUAL = {
    1005007345460326: (6.38,  "Filtro plastico..."),
    1005006994544782: (11.99, "Limpa vidro..."),
}
```
Foram decisão explícita dele: eu não consegui confirmar no AliExpress (o
bot-check bloqueou) e a regra automática **recusa** apagar de propósito,
porque os dois dias caros são vizinhos, não pico isolado.

**A regra automática de oferta dupla:**
```python
RAZAO_OFERTA_DUPLA = 1.4    # caro/barato >= 1,4 no MESMO dia
DIAS_MIN_CONFIRMA  = 2      # e isso em >= 2 dias
maior_confiavel_oferta_dupla(dias, maiores_do_dia)
```
Ela só age quando há **prova no mesmo instante** — duas leituras do mesmo dia
com razão >= 1,4, repetido em pelo menos 2 dias. Uma evidência de um dia só é
recusada.

### ⭐ A emenda dias + horas (`_serie_curta`)

**O defeito:** com leituras horárias, o desenho usava **só** as horas (~21h) —
o cartão dizia "rastreando há 9 dias" e mostrava uma reta de um dia.

**A regra:** dias **antes** do primeiro dia coberto pelas horas, mais as
horas. Nenhum dia tem as duas fontes.

```python
inicio = min(dias_cobertos)
antes  = [[k[5:], round(v,2)] for k,v in sorted(dias.items()) if k < inicio]
return antes + [[q[5:16].replace("T"," "), v] for q, v in horas]
```

As três fontes de preço:
```
estado/precos_vistos.jsonl   diário,  id como INT
estado/precos_agora.json     instantâneo horário, id como STR
estado/precos_horas.jsonl    horário, GITIGNORED, ~92 pontos/produto
```
⚠️ O `int` vs `str` do id já causou `KeyError: '_todos'`. O conserto ficou em
`_visto_em`, upstream (`408ba01`): `serie.get(pid) or serie.get(_inteiro(pid))`.

### A capa quando ninguém passa na régua (`marcar_capa`)

Novo desvio: se nenhum candidato passa, escolhe a **maior queda real**
