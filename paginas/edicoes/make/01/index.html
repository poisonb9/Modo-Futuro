01
A make · Hyunjin

O segredo da bochecha de bolinho fofo

O idol do Stray Kids conquistou o visual clássico de dumpling com uma pele super hidratada e viçosa.

Passo a passo
  1. Hidratar bem a pele do rosto
  2. Garantir o efeito de bochecha macia igual uma massa fofinha
  3. Aplicar o toque final de iluminador nas bochechas
O que foi usado
  • Iluminador para as bochechas
  • Hidratante facial para efeito de massa fofinha
02
A make · Lily

O poder dos tons frios e lavanda

A cantora do NMIXX chamou atenção com uma maquiagem impecável em tons frios e cílios marcantes.

Passo a passo
  1. Destacar o olhar com cílios longos
  2. Deixar a boca super brilhante
  3. Aplicar maquiagem em tons frios
  4. Usar o tom de lavanda no visual
O que foi usado
  • Maquiagem em tom de lavanda
  • Produto para brilho labial
  • Máscara para cílios longos
03
A make · Wooyoung

Contorno profundo para esculpir o rosto

O integrante do ATEEZ passou por uma técnica de sombreamento para valorizar sua estrutura óssea marcante.

Passo a passo
  1. Aplicar a técnica de sombreamento no côncavo
  2. Fazer o sombreamento no nariz
  3. Esculpir o formato do rosto com contorno profundo
O que foi usado
  • Maquiagem para contorno profundo
  • Sombra para técnica de sombreamento
04
A make · Ahyeon

O conceito gótico romântico perfeito

A idol do BABYMONSTER planejou seu próprio visual e usou lentes coloridas para arrasar.

Passo a passo
  1. Desenhar em papel o conceito gótico romântico desejado
  2. Colocar as lentes de contato coloridas verdes
  3. Dar acabamento de pele e lábios com efeito de orvalho
O que foi usado
  • Lentes de contato coloridas verdes
  • Maquiagem para pele e lábios com efeito de orvalho
05
A make · Jiwoo

Maquiagem de fada brilhante à prova de suor

A idol do NMIXX desenhou seu próprio conceito misterioso para se transformar em uma joia humana.

Passo a passo
  1. Desenhar o conceito misterioso e brilhante de fada
  2. Aplicar mica para dar o brilho de joia aos cosméticos
  3. Usar polímeros formadores de filme para criar uma camada invisível contra o suor
  4. Aplicar bloqueadores específicos para a linha do cabelo
O que foi usado
  • Mica para brilho de joia
  • Polímeros formadores de filme contra umidade
  • Bloqueadores para a linha do cabelo
